# NewsVoiceWAV — 뉴스보이스 WAV v5.18

필리핀 뉴스 브리핑을 갤럭시 기기의 한국어 TTS로 음성화하고 세로형 카드뉴스 MP4를 생성하는 안드로이드 앱입니다.

## 현재 단일 제작 기준

`VIDEO_V5_*` 및 과거 README 지침은 변경 기록이며, 이 문서의 현재 규칙을 대체하지 않습니다.

1. **뉴스 대본**: 기사 첫 줄은 표시 전용 제목이며 읽지 않습니다. 두 번째 줄부터 낭독 본문입니다. 복수 뉴스를 `===` 또는 `---`로 구분합니다. 인사 → 기사 → 앵커 한마디 → 마감은 중복 없이 한 번씩 배치하며 명시적 사용자 멘트를 우선합니다.
2. **큰 글씨 자동 스크롤**: 본문은 82px 고정의 큰 글씨와 115px 줄 간격을 사용합니다. 제목·진행바·날짜는 고정하고, 본문만 수직 영역 안에서 위쪽으로 움직입니다. 1080×1920 화면에 내용 전체를 억지로 넣지 않고 입력한 문장 전체를 보존합니다.
3. **하이라이트 제거**: 이전 v5.17의 읽는 문장 청록 배경, 노란 밑줄, 이미 읽은 문장의 어두워지는 효과를 모두 제거했습니다. 본문은 항상 흰색이고 기존 숫자만 노란색으로 유지합니다.
4. **24fps 부드러운 이동**: 3px 단위의 스크롤 양자화를 제거하고 부동소수점 위치를 사용하며 초당 24프레임으로 렌더링합니다. 문장 시작·종료는 실제 PCM WAV 길이로 동기화하며, 문장 내부의 이동은 글자 길이에 따른 보간값입니다. 단어 단위 강제 정렬 방식은 아닙니다. 읽는 중 본문 확대 줌을 제거해 글씨를 안정적으로 유지합니다.
5. **활기찬 오프닝 음악 자동 재생**: 6초짜리 **자체 제작 신곡**을 앱이 자동 생성·설치하며 MP4를 만들 때마다 항상 앞부분에 연결합니다. 밝은 멜로디, 짧은 화음, 베이스와 리듬을 포함합니다. 사용자가 직접 등록한 정상 WAV는 계속 우선하며, 자동 내장 음악은 버전별로 적절히 갱신됩니다. WAV만 저장하면 음악을 혼합하지 않고 음성만 저장합니다. 기존에 승인한 특정 음원을 복제한 것은 아닙니다.
6. **기존 디자인 유지**: 승인된 네이비 카드·노란 숫자·표지·날짜 표시·뉴스 진행바·9:16 세로형 영상 유지. 기사 제목을 음성으로 읽지 않습니다.
7. **저장**: 다운로드/NewsVoiceWAV 아래 WAV와 MP4 별도 저장. 영상은 12분 제한. 24fps 인코더 지원 여부는 제조사 기기별로 다를 수 있습니다.
8. **취재 정책**: 필리핀 뉴스 환율 관련 기사·분석 제외는 입력 원고 준비 단계의 정책입니다. 앱 자체가 뉴스 사실 검증 또는 환율 문장 삭제를 자동 수행하지는 않습니다.

## v5.18 버전 표시와 설치

- 단일 버전 변수 `releaseVersion`은 `app/build.gradle`의 `5.18`입니다. 이 값이 Android `versionName`, 런처 및 설치 화면의 `뉴스보이스 WAV 5.18`, 원본 APK 파일명 `NewsVoiceWAV-v5.18-debug.apk`에 공통으로 반영됩니다. `AndroidManifest.xml`에는 버전이 하드코딩되어 있지 않습니다.
- 앱 패키지 ID: `com.newsvoice.tts.autovideo.v518`. v5.17과 **별도 설치**이므로 기존 앱의 TTS 음성 설정이나 사용자 WAV는 새 앱으로 자동 복사되지 않습니다.
- JDK 17, Android SDK 35, Gradle 8.9 / Android Gradle Plugin 8.7.3.
- GitHub Actions의 `NewsVoiceWAV-v5.18-Upbeat-Smooth-Scroll-debug-apk` artifact ZIP에서 해당 APK 파일을 다운로드하거나 Android Studio에서 빌드할 수 있습니다.
- GitHub CI 검증은 삼성 갤럭시의 실제 하드웨어 인코더·TTS 품질·MP4 영상/음악 청취 테스트와 동등하지 않습니다.

## 주요 이용 방식

- 수동: 원고 입력 → 방송체 검수 → TTS WAV 합성 → WAV 및 MP4 생성/저장.
- 자동: 사용자가 연결한 HTTPS 뉴스 원고 서버가 있을 때 예약 수신 및 제작. 서버가 없다면 자동 취재 및 파일 전송은 완료되지 않습니다.
- 내장 오프닝 음악은 별도 음원 파일 다운로드 없이 자동 생성됩니다. 사용자가 원하면 앱 내 WAV 교체 버튼으로 본인 음악을 사용할 수 있습니다.

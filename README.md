# NewsVoiceWAV — 뉴스보이스 WAV v5.17

한국어 아나운서 음성(WAV)과 필리핀 뉴스 카드(1080×1920 MP4)를 생성하는 안드로이드 앱입니다.

## 현재 적용되는 단일 제작 규칙

이 문서만 최신 작동 기준으로 사용합니다. `VIDEO_V5_*` 문서와 과거 버전 설명은 기록용이며 새로운 지침과 혼용하지 않습니다.

1. 대본의 **첫 줄은 화면용 뉴스 제목**, 둘째 줄부터 읽을 뉴스 본문입니다. 제목은 절대로 TTS로 읽지 않습니다. 별도의 줄에 `===` 또는 `---`를 넣어 뉴스를 나눕니다.
2. 시작 인사 → 뉴스 → 앵커 한마디 → 마감 인사는 각각 한 번씩만 등장합니다. 명시 입력된 문구가 기본 문구보다 우선합니다.
3. **v5.17 큰 글씨 자동 스크롤**: 각 기사는 하나의 논리적 슬라이드로 유지합니다. 본문은 **82px 고정 글씨**, 약 115px 줄 간격으로 배치되며, 음성이 진행되는 만큼 위로 부드럽게 이동합니다. 본문은 중앙 영역(약 8줄)에서만 보이고, 제목·날짜·진행바는 움직이지 않습니다. 아무리 긴 본문도 한 화면에 억지로 집어넣거나 글씨를 줄이지 않습니다.
4. 문장별 실제 PCM WAV 프레임 수를 기준으로 문장 전환 시점을 정하고, 현재 낭독하는 문장에 **청록색 배경과 노란 밑줄**을 표시합니다. 문장 내부에서는 글자 위치를 이용해 서서히 스크롤하며, 실제 단어 단위 음성 강제정렬이 아니므로 문장 내부의 글자 위치는 근삿값입니다. 영상 화면 갱신은 12fps 단위입니다.
5. 기존 승인 네이비 배경, 흰색 글씨·노란 숫자, 진행바, 9:16 1080×1920, 표지·날짜·마감 안내를 유지합니다. 6초 오프닝 A 타입은 **자체 제작 독창적 음악**이 기본이며, 사용자가 제공한 정확한 원본 A WAV로 교체할 수 있습니다.
6. WAV와 MP4는 Android 다운로드/NewsVoiceWAV 폴더에 별도로 저장합니다. 12분을 초과하는 뉴스 영상은 현재 제한되며, 운영체제의 TTS/MediaCodec에 따라 내보내기에 실패할 수 있습니다.
7. 필리핀 뉴스 취재의 환율 제외 정책은 원고 작성 단계에 적용됩니다. 앱은 외부 뉴스의 사실 관계를 자체 검증하거나 뉴스의 환율 관련 문장을 자동 제거하지 않습니다.

## 사용

- 수동: 원고 작성 → 기사 제목/내용 검수 → 한국어 TTS WAV 합성 → WAV 저장 → MP4 생성·저장
- 자동: 별도 연결된 사용자 HTTPS 원고 서버가 있을 때 예약 작업으로 원고 수신 및 생성
- 음성: 갤럭시 기본/삼성 한국어 TTS 엔진 이용. 여성 목소리·음질은 장치에서 직접 미리듣기로 확인

## 빌드 및 설치

- App ID: `com.newsvoice.tts.autovideo.v517`, 이전 버전과 별도로 설치
- JDK 17, Android SDK 35, Gradle 8.9 / Android Gradle Plugin 8.7.3
- `gradle :app:assembleDebug` 또는 GitHub Actions: **Build NewsVoice WAV Automatic APK**
- Artifact: **NewsVoiceWAV-v5.17-Large-Text-Auto-Scroll-debug-apk**
- CI 테스트/빌드 통과는 실제 갤럭시 한국어 음성, 재생 안정성과 미디어 인코더 정상 작동의 보장이 아닙니다. 설치 후 짧은 뉴스와 긴 뉴스의 실제 영상/음성 싱크를 확인해야 합니다.

## 설계 상 유의점

- 스크롤은 문장마다 따로 생성한 WAV의 길이를 사용합니다. **문장 시작과 끝은 측정값**이며, 문장 안에서의 스크롤은 글자 수를 이용한 보간이므로 정확한 단어 단위 추적이 아닙니다.
- 큰 글씨로 기사 전체를 스크롤하기 때문에 프레임별 다시 그리기 작업이 많습니다. 긴 대본에서는 영상 인코딩 시간이 v5.16보다 늘어날 수 있습니다.
- TTS 앱/목소리에 따라 문장별 음성 합성 연결부의 억양이 자연스럽지 않을 수 있습니다.
- 새 버전은 별도 앱이며 이전 버전의 개인 음성 엔진 설정·원본 A WAV 등록이 자동 이전되지는 않습니다.

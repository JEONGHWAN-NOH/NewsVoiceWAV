# NewsVoiceWAV — 뉴스보이스 WAV v5.16

한국어 아나운서 음성과 필리핀 뉴스 카드 MP4를 생성하는 안드로이드 앱입니다.

## 현재 적용되는 단일 제작 규칙

이 문서를 최신 작동 기준으로 사용합니다. `VIDEO_V5_*` 파일과 과거 버전 설명은 변경 이력입니다. **예전 버전의 모순된 지침을 혼합해서 적용하지 않습니다.**

1. 뉴스 원고는 **첫 줄 제목, 그 아래 낭독 본문**입니다. 제목은 화면에만 보이고 TTS로 읽지 않습니다.
2. 뉴스끼리는 별도 줄의 `===` 또는 `---`로 구분합니다. 복수 뉴스의 제목·본문을 한꺼번에 입력할 수 있습니다.
3. 필수 방송 구간은 **시작 인사 → 기사 → 앵커 한마디 → 마감 인사** 순서로 **각 한 번** 포함됩니다. 원고에 직접 작성된 구간은 앱의 기본 멘트보다 우선하며, 별도 입력 앵커 코멘트는 원고에 앵커 멘트가 없을 때만 사용합니다.
4. 1080 × 1920 세로형 MP4, 승인 네이비 본문과 흰색 텍스트/노란 숫자, 뉴스 진행 표시, 날짜 자동 표시를 유지합니다. 한 화면에 들어가는 뉴스는 카드 하나, **긴 뉴스는 같은 디자인의 다음 카드로 자동 이어집니다.** 요약·삭제 없이 원문 보존을 검증하며 해당 화면별 WAV와 동기화합니다. **v5.16은 낭독 중인 문장만 청록색으로 하이라이트하고 노란 밑줄을 표시**합니다. 문장마다 별도로 합성한 WAV의 실제 PCM 프레임 수로 강조 구간을 계산하므로 글자 수에 비례하는 추측 시간표를 사용하지 않습니다. 화면 변경 시간은 12fps 프레임 간격 내에서 양자화됩니다.
5. **6초 오프닝 음악 A 타입**은 설치 시 앱이 생성해 자동 등록하는 **독창적인 음악**입니다. 과거 사용자가 승인한 **특정 음원 A의 복제본은 아닙니다**. 그 원본 WAV를 가지고 있다면 앱에서 한 번 선택하여 기본 음악을 대체할 수 있으며 이후에는 자동 적용됩니다. 원본 음원은 사용자 제공을 전제로 합니다.
6. 로컬 저장: Android 다운로드/NewsVoiceWAV 폴더에 WAV/MP4를 별도로 저장합니다. 길이가 12분을 초과하거나 기기의 TTS/인코더가 지원하지 않는 경우는 구체적인 오류 안내가 표시될 수 있습니다.
7. 환율 관련 뉴스·표·분석 제외는 별도 뉴스 취재/대본 작성 정책입니다. 이 앱은 입력된 기사 내용의 사실 여부를 자동 검증하지 않습니다.

## 기능 구분

- **수동:** 앱 원고 입력 → 대본 검수 → WAV+MP4 생성 → 다운로드 저장.
- **자동:** 사용자가 연결한 HTTPS 뉴스 원고 서버가 있을 때 WorkManager가 원고를 가져와 생성합니다. 원고 공급 서버가 없으면 자동 취재·전송까지 완료되는 것은 아닙니다.
- **TTS:** 갤럭시의 한국어 TTS 음성을 사용합니다. 여성 여부와 자연스러움은 실제 음성 미리 듣기로 확인해야 합니다.

## 설치 및 빌드

- 앱 ID: `com.newsvoice.tts.autovideo.v516`. 기존 버전과 별도로 설치됩니다.
- JDK 17, Android SDK 35, Gradle 8.9 / Android Gradle Plugin 8.7.3.
- Android Studio에서 `Build APK(s)` 또는 GitHub `Actions → Build NewsVoice WAV Automatic APK` 실행.
- 빌드가 성공하면 해당 실행의 **Artifacts → NewsVoiceWAV-v5.16-Sentence-Highlight-debug-apk**에서 ZIP을 받아 안의 APK를 설치합니다.
- GitHub Actions 테스트 통과만으로 갤럭시의 실제 TTS, AAC/H.264 MP4 저장과 오프닝 재생이 보장되지 않습니다. 설치 후 짧은 기사와 긴 기사 각각 시험 제작해야 합니다.

## 문제 해결

- *본문 글씨 크기 초과*: v5.15 이상에서는 한 뉴스 본문을 안전한 지점에서 여러 카드로 이어서 렌더링하도록 변경했습니다.
- *A안 오프닝 무음*: 내장 A 타입을 최초 실행 또는 MP4 합성 시 생성·등록합니다. 사용자의 원본 A WAV를 사용하려면 앱의 교체 버튼을 누르세요.
- *MP4 저장 실패*: 알림/상태의 실패 단계, 앱 버전, Android 버전, 당시 원고 길이, Logcat의 `FATAL EXCEPTION` 등을 확인합니다. TTS PCM WAV 형식, 기기 인코더와 여유 저장 공간도 영향이 있습니다.
- 새 APK 설치 오류: 안드로이드 설치 권한을 확인하고, 기존 앱과 패키지/서명키 충돌 여부를 점검합니다.

### v5.16 주의사항

- 짧은 뉴스, 여러 문장, 긴 뉴스 분할, 인사말·앵커 멘트에도 문장 강조를 적용합니다. 제목은 계속 낭독하지 않습니다.
- 문장별 합성을 위해 TTS 호출 수가 증가할 수 있어 긴 뉴스의 제작 소요 시간이 늘어날 수 있습니다.
- 특정 TTS 엔진은 문장별 별도 합성에서 자연스러운 연결에 차이가 있을 수 있습니다. 사용자 기기에서 실제 청취 및 MP4 재생 검증이 필요합니다.
- 이전 v5.15와 다른 패키지로 설치되며 오프닝 원본 A안 WAV와 음성 설정은 앱 간 자동 이전되지 않습니다. 새 앱에는 자체 제작 A 타입 음악이 기본 등록됩니다.

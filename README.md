# NewsVoiceWAV — 뉴스보이스 WAV v5.23

한국어 뉴스 대본을 갤럭시 TTS로 낭독하고 1080×1920 세로형 MP4 뉴스 영상, WAV 음성, 카카오톡 공유용 표지 JPG를 생성하는 Android 앱입니다.

## v5.23 승인 내용 및 정확한 설정

1. **본문 크기**: v5.22의 64px 글씨를 **60px**, 줄 간격 92px을 **88px**로 한 단계 더 작게 변경합니다. 기존 흰색 본문·노란색 숫자, 고정 제목과 진행바, 9:16 디자인을 유지하고 대본을 줄이거나 생략하지 않습니다.
2. **음성 우선 스크롤**: 아나운서의 PCM WAV 재생 시간을 그대로 유지하며, 화면의 본문 스크롤 좌표만 **0.7초(700ms) 뒤**의 위치로 계산합니다. 즉 영상 재생 시각에서 700,000마이크로초를 빼고 실제 문장별 WAV 길이에 근거한 보간 곡선을 평가합니다. 최초 낭독부터 0.7초간 본문은 움직이지 않습니다. 30fps는 유지됩니다.
3. **매끄러운 동기화**: 문장별 실제 WAV 프레임 길이와 원고의 누적 글자 수를 기준으로 단조 C1 연속 보간을 적용합니다. 하이라이트·밑줄·읽은 문장 흐림을 다시 넣지 않습니다. 글자별 강제정렬은 없으므로 정확한 단어 단위 추적을 보장하지는 않습니다.
4. **기사 전환과 마지막 화면**: 기사마다 음성 시작 전에 **0.75초 무음 구간**을 두어 이전 기사의 스크롤을 0.7초 늦게 완료해도 화면을 일찍 바꾸지 않습니다. 다음 기사 화면은 다음 음성보다 약 0.05초 먼저 등장합니다. 마지막 기사 뒤에는 **0.8초 무음 구간**을 추가해 0.7초 뒤의 최종 스크롤 화면을 보여준 뒤 영상을 마칩니다.
5. **뉴스 표지**: MP4 첫 6초는 기존 필리핀 뉴스 표지 고정. 같은 화면을 JPG 파일로 자동 저장합니다. Android 다운로드/NewsVoiceWAV 폴더에 JPG·MP4·WAV로 저장하며 카카오톡 공유 시 JPG 먼저 공유, 이어 MP4 공유 버튼을 유지합니다. MP4 자체의 카카오톡 썸네일은 카카오톡이 선택하므로 100% 표지 고정은 보장할 수 없습니다.
6. **오프닝 음악**: 기본으로 제공되는 활기찬 6초 자체 제작 음악은 MP4마다 자동 삽입합니다. 직접 등록한 유효한 WAV 파일은 내장 음악보다 우선합니다.
7. **대본 구성**: 첫 줄 제목은 화면에만 표시하고 읽지 않습니다. 뉴스 대본은 `===` 또는 `---`로 나누며 시작 인사→뉴스→앵커 한마디→마감 인사는 한 번씩 유지합니다.
8. **한계와 검증**: PC의 자동 빌드와 순수 Java 테스트는 실제 갤럭시 한국어 TTS, 30fps 기기 인코더, 카카오톡 업로드 결과를 검증한 것은 아닙니다. 12분 동영상 제한 및 단말별 재생 지연이 남아 있을 수 있습니다.

# NewsVoiceWAV — 뉴스보이스 WAV v5.19

필리핀 뉴스 브리핑 원고를 갤럭시 한국어 TTS로 음성화하고, 9:16 카드뉴스 MP4와 카카오톡 공유용 표지 JPG를 생성하는 안드로이드 앱입니다.

## 단일 최신 제작 규칙

1. **대본**: 각 기사의 첫 줄은 화면에만 표시하는 제목입니다. 둘째 줄부터 낭독합니다. 뉴스 구분은 `===` 또는 `---`이며 시작 인사 → 뉴스 → 앵커 한마디 → 마감 인사는 중복 없이 배치합니다.
2. **v5.19 물 흐르는 스크롤**: 한 기사는 한 개의 논리적 슬라이드입니다. 본문 82px, 줄 간격 115px을 유지하고, 본문만 위로 이동합니다. 문장 단위로 위치를 다시 계산하지 않고 **기사의 첫 WAV 발화 시점부터 마지막 발화 종료까지 전체 실제 음성 재생 시간에 걸쳐 일정 속도로** 이동합니다. 공백·쉼표·문장 사이 짧은 휴지 때문에 스크롤이 끊기지 않습니다. 30fps, 부동소수점 위치, 본문 줌 없음. 본문이 한 화면에 다 들어오면 스크롤하지 않습니다.
3. **표지 우선 노출**: 이전에 승인된 필리핀 뉴스의 파랑·노랑 표지를 MP4 **0초 첫 프레임부터 6초 내내 고정**합니다. 이 시간 동안 6초짜리 밝고 경쾌한 오프닝 음악이 자동 재생됩니다. 영상 시작 구간의 I-프레임 주기를 약 1초로 설정하여 일반적인 썸네일 추출 환경에서 표지 후보를 늘립니다.
4. **표지 JPG 자동 저장**: MP4 첫 프레임에 사용한 것과 **동일한 표지 렌더러 및 방송 날짜값**으로 1080×1920 JPG 이미지를 자동 생성합니다. WAV, MP4, JPG는 `다운로드/NewsVoiceWAV`에 각각 별도로 저장합니다.
5. **카카오톡 두 단계 공유**: 앱의 `① 카카오톡용 뉴스 표지 JPG 공유`를 선택하여 카카오톡 채팅방에 사진을 먼저 올리고, `② 뉴스 영상 MP4 공유`를 선택하여 동영상을 이어서 전송합니다. 안드로이드 공유 화면에서 카카오톡을 선택합니다. 이는 표지 사진을 채팅에 **별도 사진 메시지로 보장**하는 방식입니다. **MP4 파일 자체의 카카오톡 자동 썸네일을 사용자가 100% 강제하는 기능은 아닙니다.** 카카오톡이 영상 썸네일을 자체 선택하는 상황이 있을 수 있습니다.
6. **기존 디자인 유지**: 본문 흰색·노란 숫자, 네이비 배경, 날짜, 뉴스 진행바, 화면용 제목, 하이라이트 없음, 밑줄 없음. 표지 및 화면 텍스트를 9:16 1080×1920으로 생성합니다.
7. **음악 및 사용자 설정**: 내장 6초짜리 자체 제작 활기찬 오프닝은 별도 등록 없이 MP4마다 자동 재생됩니다. 사용자가 직접 준비한 유효한 WAV를 등록하면 그 파일이 우선합니다.
8. **제약**: 동영상 길이는 12분 이내. 실제 내장 Samsung TTS 사용 가능 여부, 인코딩 속도, 30fps H.264 지원 여부는 갤럭시 기종 및 TTS 엔진에 따라 다를 수 있습니다. 문장 내부 음성·글자별 강제 정렬은 제공하지 않습니다.
9. 환율 관련 필리핀 뉴스 제외는 원고 준비 정책이고, 앱 자체가 원고의 사실관계를 검증하지는 않습니다.

## 설치 및 버전 표시

- `app/build.gradle`의 단일 `releaseVersion = '5.19'`가 APK 파일명 `NewsVoiceWAV-v5.19-debug.apk`, Android 설치 화면의 `뉴스보이스 WAV 5.19`, `versionName`을 함께 결정합니다.
- 패키지: `com.newsvoice.tts.autovideo.v519`, 버전 코드 25. 이전 v5.18과 별도로 설치되므로 이전 앱의 음성 선택·사용자 등록 WAV가 자동 이전되지는 않습니다.
- 빌드: GitHub Actions `Build NewsVoice WAV Automatic APK` → `NewsVoiceWAV-v5.19-KakaoCover-ContinuousScroll-debug-apk` artifact ZIP 안에 설치용 APK 포함.
- GitHub Actions 자동 테스트와 APK 빌드가 성공해도 사용자의 실제 갤럭시에서 음성·영상 싱크 및 카카오톡 미리보기 선택 동작까지 보장되지는 않습니다.

## 사용 절차

1. 대본 입력 → WAV+MP4 제작 → 다운로드에서 `newsvoice_....wav`, `newsvoice_....mp4`, `newsvoice_...._cover.jpg` 확인.
2. 카카오톡 공유 시 앱에서 **표지 사진 먼저 공유**, 이어서 **MP4 동영상 공유**.
3. MP4만 공유하고 싶으면 영상 파일 자체를 공유하면 됩니다. 단, 채팅방에서 보일 동영상 썸네일은 카카오톡의 선택에 따릅니다.

# NewsVoiceWAV — 뉴스보이스 WAV v5.26

한국어 뉴스 원고를 갤럭시 한국어 TTS로 낭독하고, 1080×1920 세로형 MP4 카드뉴스·WAV 음성·카카오톡 표지 JPG를 생성하는 Android 앱입니다.

## 승인된 v5.26 설정

1. **본문 한 단계 축소**: v5.23의 60px에서 **56px**, 줄 간격 88px에서 **84px**로 변경했습니다. 화면용 제목은 낭독하지 않으며, 본문 흰색·중요 숫자 노란색·네이비 배경·뉴스 진행바 디자인을 유지합니다. 원고를 축약하거나 삭제하지 않습니다.
2. **가변 속도 중앙 추종**: 실제 문장별 WAV 생성 길이와 원고의 글자 수뿐 아니라 880px 본문 폭에서 실제로 줄바꿈된 글자 위치까지 연결합니다. 각 줄의 시작 시각을 해당 문장의 WAV 길이와 누적 글자 수로 근사하고, **현재 낭독하는 줄의 기준선이 카드 본문 화면 중앙(대략 1110px 기준선)에 오도록** 시간에 따른 스크롤 목표 거리를 계산합니다. 글씨는 본문 영역 안에서 부드럽게 위로 이동하며 기존처럼 전체 기사 시간을 단순 비례시키지 않습니다.
3. **문장·줄바꿈 속도 연결**: 문장 종료 WAV 시각과 글이 실제로 넘어가는 행의 문자 경계에 타임라인 기준점을 만들고 단조 PCHIP 곡선으로 연결합니다. 이전 줄에서 다음 줄로 점프하거나 위아래로 되돌아가지 않으며 각 줄마다 속도가 자연스럽게 바뀝니다.
4. **아나운서 0.7초 먼저**: 기존에 승인된 **700ms 음성 우선 지연**은 유지합니다. 즉 영상 표시 시각에서 700ms를 뺀 음성 진행 시각을 사용하여 중앙 추종 스크롤을 계산합니다. 매우 짧은 문장에서는 현재 낭독 중인 다음 문장보다 이전 문장이 중앙에 남을 수 있습니다. **단어별 실제 타임스탬프/강제정렬이 없으므로 완전한 단어별 중앙 고정은 제공하지 않습니다.**
5. **전체 기사 보존**: 한 기사는 하나의 스크롤 카드로 표시합니다. 짧은 뉴스도 첫 줄부터 마지막 줄까지 중앙 기준선을 따라가며, 한 줄만 있는 원고는 움직이지 않습니다. 영상 30fps, 글씨 줌/읽는 문장 하이라이트/밑줄/이미 읽은 글 흐림 처리 없음.
6. **기사 전환 보호**: 기사 시작 전 0.75초 무음, 마지막 기사 뒤 0.8초 무음을 유지하고 다음 뉴스로 넘어갈 때 기존 카드 화면을 0.7초 보존합니다. 따라서 마지막 글씨가 중앙에 오기 전에 잘리는 문제를 방지하도록 설계했습니다.
7. **기존 표지·음악·공유 유지**: MP4 첫 6초의 승인된 뉴스 표지·활기찬 자체 제작 오프닝, 동일 표지 JPG 자동 저장, `다운로드/1. 필리핀뉴스` WAV·MP4·JPG·이미지 출처 TXT 저장, 카카오톡 표지 JPG 먼저 공유→동영상 MP4 공유 버튼을 유지합니다. MP4 단독 업로드 시 카카오톡에서 표시하는 동영상 썸네일 자체를 완전히 강제하지는 못합니다.
8. **검증 범위**: CI의 소스 정책 검사·순수 Java 오디오/스크롤 타임라인 테스트·Android APK 컴파일이 완료되더라도 실제 갤럭시에서의 한국어 TTS 낭독과 30fps H.264 재생·카카오톡 업로드까지 보장되지는 않습니다. 원본 원고의 사실관계 검증은 별도 뉴스 취재 과정입니다.

## 설치 및 빌드

- 앱 표시 이름: **뉴스보이스 WAV 5.24**
- Gradle 단일 버전값: `releaseVersion = '5.26'`
- Android 패키지: `com.newsvoice.tts.autovideo.v524`, 버전 코드 30
- 빌드 APK: `NewsVoiceWAV-v5.26-debug.apk`
- GitHub Actions artifact: `NewsVoiceWAV-v5.26-CenteredVoice700ms-debug-apk`
- 이전 v5.23과는 별도 앱으로 설치됩니다. 등록한 사용자 WAV 파일, TTS 설정 및 앱 데이터는 자동 이전되지 않습니다.

## 검수 중점

- 기사 원고 56px 본문과 84px 줄 간격.
- 실제 원고의 줄바꿈에 따라 낭독 위치가 화면 중앙에서 가변 속도로 이동.
- 문장/줄 경계 속도 연속·글씨 역행 및 잘림 방지.
- 700ms 음성 우선 유지, 마지막 카드 누락 방지.
- 표지 JPG·MP4와 오프닝 음악·카카오톡 공유 유지.

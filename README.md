# 광명시 종합 뉴스 V1.1

**필리핀 뉴스 5.38의 확인된 기능을 기반으로 분리한 광명시 전용 Android 뉴스 제작 앱**입니다.

- Android 앱 ID: `com.gwangmyeong.news` (필리핀 뉴스와 별도 설치)
- 음성: 기기 한국어 TTS → WAV
- 영상: 1080×1920 세로 MP4, 기사별 이미지 등록, 번호별 화면 전환 및 음성 연동
- 저장: `다운로드/광명시 뉴스/YYYY-MM-DD/`
- 표지: 남색·파랑·빨강·노랑 방송 디자인, 광명시 제목과 한국시간 날짜 자동 표기
- 기존 필리핀 뉴스 5.38·5.37 원본은 수정하지 않았습니다.

자세한 내용: [광명시 뉴스 V1.1 개발·설치 안내](README_GWANGMYEONG_V1.1.md)

**빌드:** GitHub Actions의 `Build Gwangmyeong News V1.1 APK` 워크플로를 확인하세요. 성공 시 `GwangmyeongNews-v1.1-debug-apk` 산출물로 테스트 APK가 생성됩니다. 최종 설치와 오디오·카드·MP4 검증은 별도입니다.

**주의:** 뉴스 사실의 진위 검증은 앱이 대신하지 않습니다. 검증된 광명시 뉴스 대본을 입력하세요.

# NewsVoice v6.2 시험판

기존 v6.0/v6.1 유지. 독립 패키지 `com.newsvoice.tts.v62`.

## 자료 등록

- `첫 번째 뉴스입니다`, `2번 뉴스입니다`, `다음 뉴스입니다`를 섞어 사용해도 구분합니다. 제목·본문·`===` 형식도 지원합니다.
- 사진 1~8 독립 등록/교체. 대본 수정 후 사진을 지우지 않습니다. 대본과 사진 개수를 표시하고 누락을 알려줍니다. 대본이 바뀌면 제작 전에 순서 확인 후 다시 연결합니다.
- 카카오톡용 360×640, YouTube용 720×1280 MP4를 Fast Start로 제작합니다.

## 카카오톡 설정 (최초 1회)

1. https://developers.kakao.com 에서 정환님 소유 앱을 생성합니다.
2. 네이티브 앱 키 설정의 Android 패키지 `com.newsvoice.tts.v62`와 NewsVoice 화면의 **이 APK의 키 해시 복사**로 얻는 값을 등록합니다. 시험판 재빌드로 서명이 바뀌면 키 해시를 갱신합니다.
3. 제품 링크 관리에 `https://drive.google.com` 및 `https://www.youtube.com`을 등록합니다.
4. 네이티브 앱 키(관리자 키 아님)를 앱 내부 입력란에 저장합니다. 외부 소스에 키를 기록하지 않습니다.

## 매일 배포

1. 영상 일괄 제작. Drive에 경량 영상 저장 버튼으로 Drive 앱을 선택해 업로드합니다.
2. 해당 파일의 일반 액세스를 '링크가 있는 모든 사용자 / 뷰어'로 변경하고 파일 링크를 복사해 등록합니다. 비공개 자료에는 공개 설정하지 않습니다. 로그인하지 않은 기기에서도 열리는지 확인합니다.
3. YouTube용 영상을 일부 공개 또는 공개로 올리고 개별 영상 링크를 등록합니다.
4. 카드 보내기 버튼을 누르면 공식 카카오 SDK가 승인 표지의 상단을 이미지로 업로드하고, 실제 두 버튼이 있는 피드 메시지를 구성합니다. 카카오톡에서 수신자를 직접 선택해 전송합니다. 링크 경고가 있으면 카드 전송을 중단합니다.
5. 수신자 기기에서 두 버튼의 연결과 재생을 확인합니다. Google Drive는 파일 미리보기 방식이며 카카오톡 자체 MP4 첨부 재생과 동일하지 않습니다. 사전 계정 및 실제 서비스 검증 없이는 정식판으로 확정하지 않습니다.

예비 방식: 기존 MP4 첨부 및 문자 링크는 별도 버튼으로 유지합니다. 예비 방식에는 카드 하단의 실제 버튼이 없습니다.

# 광명시 종합 뉴스 V1.1 (5.38 기반 독립 앱)

## 원본 보존
- 필리핀 뉴스 원본: `feature/v5.38-numbered-news` (수정 금지)
- 5.37 백업: `backup/v5.37-gallery-news-images-2026-11-23`, `backup/v5.37-news-image-picker-2026-11-23` (수정 금지)
- 광명시 전용 개발: `feature/gwangmyeong-news-v1.1`
- 기존 GitHub 저장소를 공유하지만 **Android 패키지 ID는 `com.gwangmyeong.news`로 분리**되어 별도 앱 설치가 가능합니다.

## 광명시 앱 특징
- 표시 이름: **광명시 종합 뉴스 1.1**
- 한국시간(Asia/Seoul)에 따른 날짜 표기
- 기사별 소제목과 사진 등록 및 번호별 화면 전환은 필리핀 뉴스 5.38 기능을 기반으로 유지
- 앱 내 한국어 기기 TTS, WAV·9:16 MP4, 뉴스 카드, 진행바
- 날짜 자동 표기인 청색/적색 광명시 전용 표지 (기존 이미지 파일 대신 Canvas 원본 생성)
- 저장 폴더: **다운로드/광명시 뉴스/YYYY-MM-DD/**
- 기본 마무리 인사: 광명시 종합 뉴스
- 사진 자동 검색은 광명시 지역 참고자료 검색만 수행. 뉴스 사건 현장 사진이라고 표시하지 않음

## 소스·앱 독립성
- 필리핀 뉴스 5.38 및 5.37 브랜치는 변경하지 않습니다.
- 새 Android applicationId를 사용하므로 필리핀 앱 데이터·설치를 건드리지 않습니다.
- 현재 코드는 기존 저장소 내 별도 브랜치에 있으며 **아직 별도의 GitHub 저장소를 만들지는 않았습니다**.
- 기존 필리핀 앱 원본 에셋이 소스 브랜치에 남더라도 광명시 커버 렌더링에서는 사용하지 않습니다.

## APK 생성·설치 확인
1. GitHub **Actions → Build Gwangmyeong News V1.1 APK** 실행 로그를 확인합니다.
2. 성공하면 **GwangmyeongNews-v1.1-debug-apk** Artifact에서 다운로드할 수 있습니다.
3. ZIP을 풀고 `GwangmyeongNews-v1.1-debug.apk`를 설치합니다.
4. 테스트 버전의 debug 서명 APK이며, 향후 배포 버전은 별도의 고정 서명 설정이 필요합니다.
5. 갤럭시에서 긴 대본 낭독, 기사 사진 전환, MP4 재생, 실제 다운로드 파일 저장을 추가 검증해야 합니다.

## 사실 확인
앱은 뉴스 제작 도구입니다. 입력된 광명시 뉴스 사실의 진위나 출처는 자동 보장하지 않습니다.
일간 브리핑은 공식 발표와 지역 언론의 원문을 교차 검증하고, 타 시·군 기사와 과거 중복 기사를 제거하여 별도로 준비해야 합니다.

# NewsVoiceWAV — 뉴스보이스 WAV v5.22

한국어 여성 아나운서용 갤럭시 TTS와 9:16 뉴스 카드 MP4를 만드는 안드로이드 앱입니다.

## 현재 승인된 기능과 v5.22 개선

1. **본문 글씨**: v5.20의 72px을 **64px**으로, 줄 간격 100px을 **92px**으로 조정했습니다. 본문은 흰색, 숫자는 노란색이며 제목은 화면에만 표시하고 읽지 않습니다. 글씨를 자동으로 더 작게 줄이거나 원고를 삭제하지 않습니다.
2. **음성·스크롤 속도 동기화**: 전체 MP4 음성 길이만으로 평균 속도를 계산하던 v5.19와 달리, v5.22은 실제 문장별 TTS PCM WAV 종료 시각과 원고의 누적 글자 수를 기준점으로 사용합니다. 기준점 사이를 **단조 C1 연속 보간(PCHIP 가중 조화 평균 속도)**으로 연결하여 문장·공백 경계에서 갑자기 멈추거나 뛰어오르지 않도록 구성합니다. 각 기사마다 곡선을 한 번 계산하고 매 프레임 캐시된 속도로 그립니다.
3. **동기화 정밀도**: 음성 문장 시작과 종료 시점은 실제 측정한 WAV 프레임에 근거합니다. 문장 내부는 실제 단어별 강제정렬이 아니라 글자 위치에 기반한 보간이므로 **모든 단어의 정확한 순간과 화면 위치가 일치한다는 보장은 없습니다.** 같은 속도로만 흐르던 과거 방식보다는 기사별 낭독 리듬 차이를 반영합니다.
4. **음성 우선 스크롤 지연**: 화면의 스크롤 좌표만 실제 음성 위치보다 **0.3초(300ms) 늦게** 계산합니다. WAV 음성 시작 시각과 속도를 변경하지 않습니다. 기존 문장별 보간 곡선은 유지하며, 기사 마지막에서 남은 300ms 화면 이동을 완료한 후 다음 카드로 넘어가도록 조정했습니다. MP4 렌더링은 30fps로 진행하며 장치에 따라 재생 지연이 추가될 수 있습니다.\n5. **영상 디자인**: 1080×1920 (9:16), 30fps, 네이비 배경과 큰 흰색 본문, 노란 숫자, 제목·날짜·진행바 고정. 하이라이트·밑줄·읽은 문장 어둡게 표시 효과 없음.
6. **카카오톡용 고정 표지**: 영상 첫 **6초 동안 뉴스 표지**를 유지하고, 영상 첫 화면과 동일한 표지 JPG를 별도 생성합니다. Android 다운로드/NewsVoiceWAV에 JPG, MP4, WAV를 저장하고, 앱에서 표지 사진 먼저 공유 → MP4 나중 공유 버튼을 사용할 수 있습니다. MP4의 **카카오톡 자동 썸네일을 100% 강제할 수는 없습니다**.
7. **오프닝 음악**: 기존 활기찬 6초짜리 자체 제작 음악을 MP4마다 자동으로 재생합니다. 유효한 사용자 WAV로 교체했다면 그 음악을 우선합니다.
8. **뉴스 구성**: 대본의 첫 줄 제목은 표시 전용이며 그 아래 본문만 낭독합니다. `===` 또는 `---` 줄로 뉴스를 구분합니다. 시작 인사 → 기사 → 앵커 한마디 → 마감 인사가 한 번씩 적용됩니다.
9. **운영 범위**: 수동 원고 저장 및 영상 제작은 앱에서 수행할 수 있습니다. 자동 원고 수신은 사용자가 연결한 HTTPS 서버가 있어야 합니다. 영상 12분 제한 및 기기 H.264/AAC/TTS 인코더 호환성 제한이 있습니다. 필리핀 뉴스 환율 항목 제외는 원고 취재 정책으로 앱 자체가 팩트를 검증하거나 환율 내용을 자동 삭제하는 것은 아닙니다.

## 설치 및 빌드

- Android 패키지: `com.newsvoice.tts.autovideo.v522`
- 설치 표시 이름 및 버전: **뉴스보이스 WAV 5.22**
- 실제 APK 파일명: **NewsVoiceWAV-v5.22-debug.apk**
- Gradle의 단일 `releaseVersion='5.22'` 값으로 APK 이름, Android 앱 표시 이름, 버전명이 함께 변경됩니다.
- Android SDK 35, Gradle 8.9, JDK 17. GitHub Actions workflow `Build NewsVoice WAV Automatic APK`, artifact `NewsVoiceWAV-v5.22-VoiceFirst300ms-debug-apk`.
- 패키지가 변경되어 v5.21과 별도 설치됩니다. 이전 앱에서 등록한 목소리, 원본 오프닝 음악 또는 설정은 자동 이전되지 않습니다.
- CI 테스트와 APK 빌드가 성공하더라도 사용자 갤럭시에서의 TTS와 MP4 재생 및 카카오톡 업로드를 보장하는 것은 아닙니다. 실제 단말에서 긴 기사와 짧은 기사 각각 테스트해야 합니다.

## 검수

- 글씨 64px / 92px 줄 간격, 뉴스 제목 음성 미낭독.
- 문장별 WAV 타임스탬프를 기반으로 한 단조 스크롤을 300ms 지연하여 적용하고, 문장 경계에서 속도 차이를 최소화.
- 하이라이트 없음, 본문 잘림 없음, 짧은 기사에서 스크롤하지 않음.
- 기존 6초 표지·오프닝 음악, JPG 자동 생성, 카카오톡 공유 버튼 유지.

# 필리핀 뉴스 방송 제작 지침 v6.2

2026년 11월 25일 승인된 NewsVoice WAV v5.42 Lite용 텍스트 중심 방송 기준입니다. 방송은 ‘자막이 있는 라디오 뉴스’로 구성합니다. 기존 v6.1.3과 v5.41 자료는 보존합니다.

## 방송 자료

- 정치·경제·사회·사건사고 각 3건, 총 12건을 기본으로 하며 한국 관련 중요 특별뉴스는 별도 검토합니다. 앱의 기존 기사 수 제한을 넘는 경우 회차를 나눕니다.
- 환율 뉴스와 환율 지표는 제외합니다.
- 기사 출처를 확인하고 기사일·사건일, 예정·확정을 구분합니다. 필리핀 현지 기준시각을 표시합니다.
- UTF-8 대본 TXT와 기사 출처 TXT를 제공합니다. 출처 목록은 낭독 대본과 분리합니다.
- 사진·삽화·표지 이미지·아나운서 이미지의 생성, 검색, 다운로드 및 이미지 묶음 제공은 하지 않습니다.
- 앱에는 대본 TXT를 직접 불러오거나 붙여 넣습니다. 기존 ‘제목 + 본문 + ===’ 구분 형식과 ‘첫 번째 뉴스입니다’ 등의 순번 형식을 유지합니다.

## 화면과 소리

- 9:16 화면에 상단 기사 제목, 노란 밑줄과 확대된 본문을 표시합니다.
- 본문은 기존 음성 타임라인에 맞춰 스크롤하며 음성 우선 0.7초 설정을 유지합니다.
- 순번 멘트와 기사 제목 전환, 기존 음성 설정, 오프닝 음악, WAV·MP4 제작을 유지합니다.
- 사진 표지 대신 오프닝 음악 구간에는 텍스트 제목·날짜·시각을 표시합니다. 별도 JPG 표지는 만들지 않습니다.

## 일정 적용 상태

이 파일은 제작 내용에 관한 지침이며 예약 실행 설정을 변경하지 않습니다. 기존 예약 ID, 실행 시각, 시간대, 반복 주기, 활성화·일시정지 상태와 알림 설정은 그대로 보존해야 합니다.

현재 연결된 도구에서 기존 ChatGPT 예약의 원문·일정·활성화 상태를 조회하거나 수정할 수 있는 대상을 확보하지 못했습니다. 로컬 Codex 자동화 설정 폴더에서도 해당 예약을 찾지 못했습니다. 따라서 예약 작업에 v6.2가 반영됐다고 간주하지 않습니다. 기존 예약 내용을 조회할 수 있을 때 이미지 관련 지침만 위 기준으로 바꾸고, 일정과 활성화 상태의 변경 전후 일치를 확인해야 합니다.

# v5.32 테스트 변경 명세 (승인 전)

기준: backup/v5.31-approved-20261122
작업 브랜치: test/v5.32-news-ui-20261122

## 요구사항
1. 기존 승인 버전과 서명키, main 브랜치, 배포 APK를 변경하지 않는다.
2. 뉴스 대본 입력 화면에 '대본 전체 지우기' 버튼을 제공한다. 확인 후 입력 텍스트만 지우며 WAV/MP4/저장 파일은 삭제하지 않는다.
3. 새 대본을 붙여넣으면 분야별 뉴스 항목을 분류하고 항목별 제목과 요약을 생성한다. '안녕하십니까?' 인사말을 뉴스 제목으로 사용하지 않는다.
4. 카드 목록의 왼쪽에 기사 관련 사진, 오른쪽에 분류·제목·요약을 표시한다. 기존 제공 사진이 주제에 맞으면 재사용한다.
5. 기사 사진이 없거나 실패하면 기본 이미지/안전한 플레이스홀더를 표시하고 UI가 깨지지 않도록 한다.
6. 아나운서 이미지가 누락된 경우 표시 경로와 리소스 로딩을 점검한다.
7. 새 대본 적용 시 기존 뉴스 제목과 사진을 갱신한다. 실제 기사와 무관한 사진·가상 통계를 사실처럼 표시하지 않는다.
8. 기존 WAV, MP4, 카카오톡 공유 기능의 회귀 테스트를 수행한다.

## 승인 게이트
- 별도 테스트 APK 설치 및 실제 갤럭시 확인 후 사용자 승인 시에만 정식 반영.
- 서명키는 저장소에 올리지 않는다.
- 빌드 및 설치 성공 전에는 테스트 APK 완료라고 표시하지 않는다.

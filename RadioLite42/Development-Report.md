# NewsVoice Radio Lite v4.0 개발 및 운영 기준 (2026-11-26)

상태: 독립 Android 앱 소스 및 Windows 방송 제작 도구 작성, APK 빌드 및 서명 검증 완료. Galaxy 실기기 검증은 아직 미완료. 기존 v3.2 및 승인된 과거 버전은 변경하지 않았음.

## 확정 설계
- MP3 48kbps 모노 + UTF-8 SRT 자막, ZIP 1개로 저장·공유. 5분 방송 2MB 이하 목표.
- 검은색 배경, 흰색 자막, 현재 낭독 문장을 읽기 영역 상단 33%에 배치. 재생 시계 기준 0.7초 지연, 연속 스크롤.
- ZIP 또는 MP3/SRT 개별 불러오기, 재생·일시정지·탐색·속도·글자 크기 조절, 백그라운드 재생 서비스, 오프라인 재생.
- 영상·사진·제목·앵커 한마디 기능 제외. 앱에 인터넷 접근 권한 없음. 영구 WAV 불필요.
- 오프닝 6초와 승인된 음성은 외부 입력을 사용. This Voice Voice 등에서 제작한 실제 음성을 공급해야 함. Android 앱 자체의 TTS/MP3 인코딩은 미구현이며 Windows 제작 도구가 MP3 및 SRT를 제작함.
- 필리핀 뉴스 기존 취재 기준과 예약 설정 변경 없음.

## 확인 결과
12개 합성 테스트 음원(각 24.5초) 및 6초 오프닝으로 300초 파일 생성 성공. MP3 1,800,524바이트, SRT 545바이트. 마지막 자막 종료시간 00:05:00,000. 테스트는 합성음으로 진행했으므로 실제 음성 품질과 ZIP 압축률은 검증하지 않았음. 실제 방송 패키지는 약 1.8~2MB 예상.
